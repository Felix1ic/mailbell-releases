# 信铃 · Android 安装包

按可配置关键词识别网易邮箱与 TradingView 系统通知，触发循环响铃，并支持手动停止。

[下载最新版本与查看说明](https://github.com/Felix1ic/mailbell-releases/releases/latest)

本仓库只发布 APK、版本说明和更新元数据，不提供源码，也不包含签名私钥或用户数据。

- Android 8.0 及以上。已有版本直接覆盖安装，不要先卸载或清除数据。
- 0.2.0 起支持应用内检查、下载和请求安装更新。每日自动检查可关闭；安装仍需系统确认。
- 通知识别在本机完成；更新通过 HTTPS 联网，不上传通知、规则或警报目录。下载会验证完整性、包名、版本和原签名。
- TV 通知为初步接入，需要真机确认推送内容与合并方式。导入的警报目录是本地副本，并不代表已直接同步 TV 账户。
- 导入目录采用设备密钥 AES-GCM 加密；规则及运行记录使用原应用私有 SQLite。APK 使用代码混淆，不能保证无法反编译。
- 各通知来源应用仍需正常联网收到消息；Android/HyperOS 的通知权限和省电设置会影响后台表现。

请勿在公开问题中提交邮件正文、警报完整内容、Webhook 地址、账号凭据或签名文件。
