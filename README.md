# 信铃 · Android 安装包

按可配置关键词识别网易邮箱与 TradingView 系统通知，触发循环响铃，并支持手动停止。

[下载最新版本与查看说明](https://github.com/Felix1ic/mailbell-releases/releases/latest)

本仓库只发布 APK、版本说明和更新元数据，不提供源码，也不包含签名私钥或用户数据。

- Android 8.0 及以上。已有版本直接覆盖安装，不要先卸载或清除数据。
- 0.3.0 起可在规则页连接 TradingView，通过系统浏览器登录授权，直接同步已有警报目录。官方服务目前要求 Essential 及以上正式订阅，试用不包含。
- 目录保存在本地，由你手动刷新；可以搜索、按状态筛选并选择条目建立规则。官方接口隐藏消息正文，因此仍需确认实际通知里可见的匹配词。内部警报编号不作为匹配词。
- 邮箱触发保留。账号连接、同步或断开不会关闭邮箱规则，也不会创建、修改或删除 TV 云端警报。
- 0.2.0 起支持应用内检查、下载和请求安装更新。每日自动检查可关闭；安装仍需系统确认。下载会验证完整性、包名、版本和原签名。
- 通知识别在本机完成；只为更新及主动发起的 TV 授权/目录同步联网，不上传通知或规则。授权凭据和目录采用设备密钥 AES-GCM 加密；规则及运行记录仍使用原应用私有 SQLite。
- APK 使用代码混淆，不能保证无法反编译。无额外常驻同步服务；授权期间使用限时本机回调。
- 本版为小米测试版：150 项离线回归测试通过；真实账号授权、手机目录返回格式、通知与锁屏表现仍需实机验收。各通知来源应用需正常收到消息，Android/HyperOS 权限与省电设置会影响后台表现。

请勿在公开问题中提交邮件正文、警报完整内容、Webhook 地址、账号凭据或签名文件。
